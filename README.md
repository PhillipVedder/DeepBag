# DeepBag

A basketball training tracker and move-library concept, centred on deliberate practice and understanding your game.

**Status: planned.** This repository currently contains project notes and a license, not an application implementation. The features below describe the intended direction; they are not shipped functionality.

## Intended Direction

- A personal library of basketball moves and practice goals.
- Training and game logs for makes, misses, and repeated drills.
- Shot-location maps and progress over time.
- Custom moves and pre-session routines.

There are no setup instructions, screenshots, or test claims yet because no runnable application is checked in.
